# FCPXML DTD

Apple's `FCPXMLv1_14.dtd` is not redistributed here. The validator finds it automatically inside your Final Cut Pro install:

```
/Applications/Final Cut Pro.app/Contents/Frameworks/Interchange.framework/Versions/A/Resources/FCPXMLv1_14.dtd
```

To use a different copy, place `FCPXMLv1_14.dtd` in this folder.
